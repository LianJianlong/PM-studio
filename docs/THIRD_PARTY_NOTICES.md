# 第三方组件

本项目使用 npm 依赖及离线 draw.io。版本和来源以 `package-lock.json`、`package.json`、`vendor/drawio-version.json` 为准。

- React、Vite、Express、TypeScript、Tiptap、Univer、CodeMirror、ECharts、ExcelJS、KaTeX 等依赖保持各自版权与许可；安装后在对应依赖目录查看 LICENSE/NOTICE。
- 离线 draw.io 保留上游源码、资源和原有许可证。发布时请一并保留 `vendor/drawio/LICENSE`、子目录许可证及通知。
- `src/assets/` 为通用平台图标，不包含用户上传的登录背景或业务照片。

主项目使用 Apache-2.0；此说明不替代第三方许可审核。npm 依赖未内嵌到本源码目录，须通过锁文件安装。
